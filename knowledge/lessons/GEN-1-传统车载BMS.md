# 课程 GEN-1：传统车载 BMS——一切都在车上闭环

> 对应节点 `GEN-1`（[../domains/00-跨域层-架构与代际.md](../domains/00-跨域层-架构与代际.md)）｜ 前置：`ARCH-MS`（建议先读）｜ 预计用时 30 min
> 数字规则：文中所有具体数字凡未挂标准/论文者均为**教学示意值**，用于建立量级直觉，不是实测数据。

## 1. 为什么需要"代际"这个视角

同一个 BMS，放在 2012 年和 2026 年，功能清单可能一样，但**能力边界完全不同**——差别不在功能，而在"算力在哪里、数据通向哪里、多快能变好"。代际维度（GEN-1/2/3）就是给这个演进画刻度：

GEN-1（传统车载，On-board Standalone BMS）：全部功能本地闭环的代际形态（domain 定义）——采集、估计、保护、充电通信全在车上，车外没有任何东西参与运行。

先刻好 GEN-1 这条基线，才谈得上 GEN-2 加了什么、GEN-3 还想加什么。

## 2. 机制：GEN-1 的四个特征与三个天花板

### 2.1 特征

1. **本地闭环**：安全监控 → 保护 → 断高压，全在车端毫秒~百毫秒内完成（GB/T 38661 对 BMS 功能与精度的框架，S-03）；
2. **算力受限**：车规 MCU 算力与内存受限（domain 约束；主频百 MHz 级、Flash 数 MB 量级为教学示意值）——算法选型受此硬约束；
3. **无远程更新**：标定固化在出厂状态，改标定 = 到店刷写（OTA 演进见 `SW-06`）；
4. **数据不出车**：运行数据只进本地记录器（事故回读用），无远程分析。

### 2.2 天花板

1. **精度天花板**：算法只能用"这辆车"的数据，SOC/SOH 误差无法用车队数据系统性修正；
2. **迭代天花板**：发现问题 → 改软件 → 召回或到店刷写，周期以月计；
3. **认知天花板**：单一老化样本无法区分"电芯个体差异"与"批次缺陷"。

## 3. 工程案例：一桩 SOC 漂移投诉的两种结局（推演）

场景（教学示意值场景）：某 LFP（磷酸铁锂）车型，用户反映仪表 SOC 在中段"跳变"（机理见 `ALG-01`：平台段无 OCV 校正锚点）。

- **GEN-1 结局**：4S 店检测 → 按 TSB（Technical Service Bulletin，技术服务公报）流程到店刷写或换件；其他用户继续遭遇同样问题，直到下一次召回。修复周期：月级。
- **GEN-2 结局（对照）**：云端发现该批次/该工况组合的共性漂移 → 数据定位根因 → OTA 推送修正后的校正策略。修复周期：天~周级。

**结论**：两种代际的"车内算法"可能一模一样；差距全在数据闭环与更新通道——这正是代际的定义变量。

| 能力 | GEN-1 | GEN-2（对照） |
|---|---|---|
| 安全闭环 | 本地 | 本地（不变） |
| 数据 | 出车即断 | 车队级回流 |
| 更新通道 | 到店刷写 | OTA（UN R156 合规） |
| SOC 精度演进 | 随老化漂移 | 云端参数持续修正 |
| 售后根因分析 | 逐车排查 | 车队聚类定位 |

## 4. 工程实态

- GEN-1 至今不是"落后"代名词：**所有代际的安全闭环都必须本地完成**，GEN-1 形态是地基（观点级）。
- 存量与低价车型仍大量是 GEN-1 形态（观点级）。
- 国内对新能源车的远程监控有标准要求（GB/T 32960 系列《电动汽车远程服务与管理系统》，版本细节待核对）：严格说接入监控的车型已在"数据"维度脱离纯 GEN-1，但监控上传 ≠ 云端辅助控制——代际判定看的是**运行时谁参与决策**。

## 5. 常见误区

1. "GEN-1 = 落后淘汰"——安全闭环本地化是所有代际的共同地基；断网时 GEN-3 也要退回 GEN-1 行为。
2. "没有云端就做不了 SOC"——GEN-1 的安时积分 + OCV 校正（`ALG-01`）至今仍是主力算法，云端只是让它"变得更好"。
3. 把"有 T-Box 上传数据"的车都叫 GEN-2——上传只是数据管道；GEN-2 的判据是**云端产物是否参与改进车端运行**。

## 6. 自测

**Q1**：GEN-1 的三个天花板分别卡住了什么？
**Q2**：为什么说"断网时 GEN-3 也要退回 GEN-1 行为"？
**Q3**：一辆装了 T-Box、每分钟上传车辆状态，但没有 OTA 通道、云端也不做分析的车——按本课判据它是 GEN-1 还是 GEN-2？

<details><summary>答案</summary>

- Q1：精度（只有本车数据）、迭代（刷写以月计）、认知（无车队对照，难分个体差异与批次缺陷）。
- Q2：安全闭环从不依赖云端；断网剪断的是"增强项"（参数更新、远程分析），车端退化为纯本地闭环——即 GEN-1 行为。
- Q3：本质仍是 GEN-1 形态 + 法规要求的远程监控管道：云端不产生改进产物、无 OTA，运行时仍是纯本地决策（按本课判据，教学示意值场景）。
</details>
