# 课程 SAFE-04：安全机制与故障反应时间（FTTI）

> 对应节点 `SAFE-04`（[../domains/02-安全设计.md](../domains/02-安全设计.md)）｜ 前置：[SAFE-02](SAFE-02-HARA.md)、[SAFE-03](SAFE-03-ASIL分解.md) ｜ 预计用时 60 min
> 数字规则：GB 38031-2020 的热扩散报警要求为标准内容（S-02，表述以原文为准）；其余具体时间数字均为**教学示意值**。

## 1. 为什么机制必须和"失效速度"匹配

安全目标（`SAFE-02`）只回答"要避免什么"，安全机制（Safety Mechanism）才是落地手段：检测故障 + 控制故障 + 减轻危害。节点约束给定了匹配原则：**故障反应时间需与电化学失效速度匹配（过流 ms 级，热失控 min 级）**——保护动作慢于危害发展，机制等于不存在。

## 2. 机制展开：四类保护 + FTTI 时间链

**（1）四类基础保护机制**（阈值均为教学示意值，实际按电芯规格与标定矩阵）

| 机制 | 检测对象 | 分级动作（递进） |
|---|---|---|
| 过充保护 | V_cell 上限（4.25 V 示意） | 报警 → 限充/停充 → 断高压 |
| 过放保护 | V_cell 下限（2.50 V 示意） | 报警 → 限放 → 断高压 |
| 过温保护 | T_max（60°C 示意） | 降功率 → 停充 → 断高压 |
| 过流保护 | I 超限（kA 级短路另由熔断器兜底） | 限功率 → 断高压 |

阈值设计两要素：**裕量**（动作阈值与电芯极限之间留出采集误差+电芯离散性空间）与**防抖/迟滞**（debounce/hysteresis，防止在阈值附近抖动振荡——但防抖时间计入故障反应预算，见手算）。

**（2）FTTI 时间链（四个术语均源自 ISO 26262-1:2018，逐个解释）**
- **FTTI**（Fault Tolerant Time Interval，故障容错时间间隔）：从故障发生到危害事件不可逆的最短时间——由危害的电化学/物理速度决定，设计者不能选择它；
- **FDTI**（Fault Detection Time Interval）：检测耗时 = 采样周期 + 滤波/防抖；
- **FRTI**（Fault Reaction Time Interval）：反应耗时 = 判断 + 通信 + 驱动 + 执行器动作；
- **FHTI**（Fault Handling Time Interval）= FDTI + FRTI，设计要求：**FHTI < FTTI**（留余量）。

预算是逐环节加出来的：采样、滤波、判决、通信、驱动、接触器分断，一环不能漏。

## 3. 手算实例：过流与热失控的两条时间预算

**例 A：外部短路过流（教学示意值）**

| 环节 | 耗时 |
|---|---|
| 电流采样周期 | 10 ms |
| 滤波/防抖确认 | 20 ms |
| **FDTI 小计** | **30 ms** |
| 判决 + 驱动 | 10 ms |
| 接触器分断（含灭弧） | 40 ms |
| **FRTI 小计** | **50 ms** |
| **FHTI = FDTI + FRTI** | **80 ms** |

设该工况下连接器/电芯的损伤耐受时间为 200 ms（示意）→ FTTI ≥ 200 ms → 余量 = 200 − 80 = **120 ms**（FHTI 占 FTTI 的 40%）。敏感性检查：防抖从 20 ms 放宽到 100 ms → FHTI = 160 ms，余量只剩 20 ms——**防抖不是免费的**。

**例 B：热失控（min 级，对照）**
- 标准口径：GB 38031-2020（S-02）要求热扩散试验中提供热事件报警并留出乘员逃逸时间（5 min 量级，表述以原文为准）；GB 38031-2025（S-01）进一步强化（细节待核对 P-05）；
- 预算：FTTI ≈ 300 s（按 5 min 口径转译，示意）→ 检测（温升率/电压骤降等热失控征兆算法）FDTI ≤ 30 s（示意）+ 报警上报 FRTI ≤ 5 s（示意）→ FHTI = 35 s，余量充足；
- **对比结论**：过流 FHTI 按毫秒设计，热失控按秒/分钟设计——同一套 BMS 两种时间尺度并存，这正是节点约束"匹配电化学失效速度"的含义。

## 4. 工程实态

- 阈值标定矩阵：阈值随温度×SOC×老化变化（`DEV-05`），不是一组常数；
- 分层防线：BMS 软件保护（可标定）→ 硬件比较器兜底（`SAFE-03` 监控通道）→ 熔断器/pyrofuse 等无源最后防线——三层失效模式互不相同；
- 执行器时间是 FRTI 的大头：接触器分断数十 ms 量级（示意），选型时纳入预算；kA 级短路交给熔断器/pyrofuse 承担；
- 确认方式：FHTI 用故障注入实测（HIL/实车，`DEV-02/03`），不是纸面计算。

## 5. 常见误区

1. 阈值贴着电芯极限设——采集误差（±2 mV 量级，示意）直接吃穿裕量；
2. 防抖拉长求稳——防抖时间在 FHTI 预算里，拉太长保护反而失效；
3. 只算软件时间——采样周期、通信延迟、接触器分断、灭弧都要计入；
4. 认为 BMS 是唯一防线——熔断器层承担 ms 级 kA 短路，BMS 管不到那个速度。

## 6. 自测

**Q1**：FHTI 由哪两段构成？设计约束是什么？
**Q2**：过流保护链路 FDTI=30 ms、FRTI=50 ms，FTTI=200 ms，余量多少？防抖 +70 ms 后还剩多少？
**Q3**：为什么热失控报警可以做秒级、而过流必须毫秒级？

<details><summary>答案</summary>

- Q1：FHTI = FDTI（检测）+ FRTI（反应）；约束 FHTI < FTTI（FTTI 由危害发展速度决定，术语源自 ISO 26262-1:2018）。
- Q2：FHTI = 80 ms，余量 = 200 − 80 = **120 ms**；防抖 +70 ms → FHTI = 150 ms，余量 **50 ms**。
- Q3：危害发展速度不同：过流的热/电磁应力在毫秒级造成损伤（FTTI 毫秒级）；热失控从触发到起火是分钟级过程（GB 38031-2020 的 5 min 报警口径），检测算法有余量做秒级运算。
</details>
