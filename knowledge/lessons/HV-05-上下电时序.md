# 课程 HV-05：高压上下电时序

> 对应节点 `HV-05`（[../domains/05-高压.md](../domains/05-高压.md)）｜ 前置：[HV-02](HV-02-预充电路.md) ｜ 预计用时 40 min
> 数字规则：文中具体数字凡未挂标准/来源者均为**教学示意值**。

## 1. 为什么需要时序管理

高压回路的建立与撤出不是"闭合/断开两个继电器"这么简单：预充必须先于主正（[HV-02](HV-02-预充电路.md)）、粘连检测必须先于一切闭合（[HV-04](HV-04-粘连检测.md)）、绝缘自检要在带载前完成（[HV-03](HV-03-绝缘监测.md)）、下电后要把母线泄放到安全电压。**顺序错了不是功能问题，是安全问题。**

时序管理两条铁律（节点约束）：**与 VCU 协调**（整车只能有一个指挥者）；**任一步失败回到安全状态**（安全态 = 继电器全断 + 母线放电 + 禁再上电，直到故障澄清）。

## 2. 机制展开

**（1）上电时序（整合前几课）**：低压上电 → BMS 自检（粘连 → 放电确认 → 绝缘 → HVIL）→ 闭主负 → 闭预充 → 电压爬升至目标 → 断预充 → 闭主正 → 高压就绪 → 报 VCU 允许行车。

**（2）下电时序**：整车请求下电 → 功率输出归零（带载分断大电流会烧触点）→ 分断继电器 → 主动/被动放电 → 母线 ≤60 V DC（人体安全电压量级的通用引用值，条款表述待核对）→ 记录状态、休眠。

**（3）状态机与协调**。典型高压状态机（示意命名）：`OFF → STANDBY → PRECHARGE → READY`（另有 `CHARGE` 支路进充电域）。BMS 与 VCU 各持一份并互验：BMS 报"高压就绪"后 VCU 才使能驱动；任何一方超时 → 回安全态。

**（4）优先级链**（从高到低，示意）：碰撞硬线 > HVIL 硬线 > BMS 内部故障 > CAN 命令。**硬线永远优先于总线**——总线可能丢帧、被干扰、被攻击。

## 3. 手算实例：下电放电电阻计算

给定：C_bus = 900 µF，V₀ = 400 V，要求 1 s 内泄放到 ≤60 V DC（教学示意值；60 V DC 为人体安全电压限的常见引用值，标准条款待核对）。

放电过程 V(t) = V₀·e^(−t/RC)，反解所需时间常数：

$$RC = \frac{t}{\ln(V_0/V_{target})} = \frac{1}{\ln(400/60)} = \frac{1}{1.897} ≈ 0.527\ \text{s}$$

- R = 0.527 / 900 µF ≈ 585 Ω → 取 E24 标称 **560 Ω**；
- 复核：RC = 0.504 s，V(1 s) = 400·e^(−1.984) ≈ **55 V** ✓
- 能量核对：½CV² = 72 J 全部落在此电阻上，峰值功率 400²/560 ≈ 286 W（瞬时）→ 选脉冲能力足够的泄放电阻（示意选型）；
- 对比：主动放电（电力电子泵回电池或耗散）可压到 ~100 ms 级（示意），代价是成本与新失效模式。

## 4. 工程实态

- 状态机在 BMS 与 VCU **双向实现并互验**，超时、非法跳变均记 DTC；
- 上电自检失败后**有限次重试**——防继电器寿命被重试风暴烧光；
- 主动放电在新平台普及；被动泄放电阻常驻母线（兼作驻车后自然泄放路径）；
- 诊断仪可请求"受控下高压"用于维修，但碰撞/严重故障路径不允许被诊断命令覆盖。

## 5. 常见误区

1. 预充未达目标就闭主正——等于没预充，浪涌全打在主正触点上（[HV-02](HV-02-预充电路.md) 白做了）；
2. 带载分断——先请求功率归零再分断，否则每次下电都在烧触点、积累粘连概率（[HV-04](HV-04-粘连检测.md)）；
3. 下电只分断不放电——残压 400 V 的母线对维修人员是致命的；
4. 只测成功路径——工程量在失败分支：每步超时怎么走、回到哪个安全态，比成功路径更值得测试。

## 6. 自测

**Q1**：上电时序里"闭主负"为什么在"闭预充"之前？
**Q2**：泄放电阻取 1 kΩ，1 s 后母线电压多少？还满足 60 V 目标吗？
**Q3**：为什么碰撞硬线信号必须绕过 CAN、直接作用于继电器驱动级？

<details><summary>答案</summary>

- Q1：先建立负极回路，预充电流才有完整通路；顺序颠倒会让电流走不确定路径（例如给不该充电的容性支路充电），也可能造成检测误判。先负后正是行业惯例（示意表述）。
- Q2：RC = 0.9 s，V(1) = 400·e^(−1.111) ≈ **132 V** > 60 V，不满足；需 t = 0.9×1.897 ≈ **1.71 s** 才降到 60 V——电阻按能量峰值好选，按时间窗核对才是关键。
- Q3：CAN 有延迟、丢帧与被攻击风险；碰撞是最高优先级事件，硬线直连保证"任何软件状态都能被物理信号推翻"。
</details>
