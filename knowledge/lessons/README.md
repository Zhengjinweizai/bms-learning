# lessons/ 课程层说明

> 定位分层：`domains/` 是**地图**（77 张节点卡片：一句话定义 + 约束），`lessons/` 是**教材**（把节点讲透），`sources/` 是**原文库**，`radar/` 是**新闻**。学习时以 lessons 为主线，domains 做导航。

## 每课的固定结构

1. 对应节点 + 前置课程 + 预计用时
2. 为什么需要它（工程动机）
3. 核心机制 / 公式（含每个符号的物理含义）
4. **手算实例**（数字自洽、可复算）
5. 工程实态（量产车怎么做）
6. 常见误区
7. 自测题（答案附文末）
8. 来源清单
9. **延伸资源（网上链接）**——必须联网核实真实 URL（禁止编造 URL/DOI），标注 A/B/C 级别与是否免费；链接同步登记 `meta/source-registry.md`

## 写作硬规则（承接项目 AGENTS.md）

- 每个方法、结论挂来源（S 编号 → meta/source-registry.md）。
- 所有用于教学的具体数字必须标注**"教学示意值"**，与实测/标准数据严格区分；没有来源的数值宁可标待核对。
- 待核对项一律登记 `meta/pending-verification.md`（P 编号）。
