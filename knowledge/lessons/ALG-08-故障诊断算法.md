# 课程 ALG-08：故障诊断算法——从"越限报警"到"看出病来"

> 对应节点 `ALG-08`（[../domains/06-核心算法.md](../domains/06-核心算法.md)）｜ 前置：[ALG-10](ALG-10-等效电路模型与参数辨识.md)、[FLT-01](FLT-01-故障分级.md)（建议）｜ 预计用时 45 min
> 数字规则：文中所有具体数字凡未挂标准/论文者均为**教学示意值**。

## 1. 为什么需要它

[FLT-01](FLT-01-故障分级.md) 的阈值矩阵是"急诊科"：电压/温度/电流越限就报警。但它只能抓**已经显形**的病。三类高危故障是"慢病"——参数悄悄变坏，等到越限已经晚了：

1. **内短路（软短路）**：单体自放电异常加速，前期只是"掉电快一点"；
2. **连接松动**：极柱电阻缓慢上涨，前期只是"压差大一点"；
3. **传感器漂移**：采样通道温漂/零漂，测量本身在说谎。

诊断算法的分工：**用模型残差与参数辨识在越限之前发现异常**。误报的代价是工单与召回（[FLT-06](FLT-06-远程诊断.md)），漏报的代价是安全事故——节点约束"误报率与漏报率需平衡"就是这个天平。

## 2. 机制展开

### 2.1 残差诊断三部曲（模型法主干）

1. **残差生成**：r_k = U_meas,k − U_pred,k。U_pred 来自 ECM + 状态估计（ALG-10/02 的模型）。健康电池的 r 在噪声带内游走；
2. **残差评价**：滑动窗口统计检验（均值偏移 / 3σ 准则），绝不用单帧——FLT-01 的"防抖三件套"这里是统计版；
3. **故障隔离**：定位是哪个单体还是哪路传感器。判别逻辑（示意）：某单体残差异常而**相邻单体差分**（ΔU）正常 → 更可能是该路采样链问题；差分同样异常 → 更可能是电芯本体问题。

### 2.2 参数漂移诊断

- 周期性在线辨识 R0（ALG-10 方法在车上低频复跑）→ **趋势**（老化，缓）与**突变**（连接松动/析锂，快）分离；
- **自放电一致性**：静置段比较各单体 dV/dt 的离散度 → 软短路筛查（实例 1）；
- 内短路的电-热交叉证据：电压异常 + 该单体局部温升（[THM-05](THM-05-热失控预警.md) 是本课的安全深化版）。

### 2.3 数据驱动补充

把残差/特征序列喂分类器（正常/内短路/传感器漂移/连接松动）。难点同 [ALG-03](ALG-03-数据驱动SOC.md)：故障标签稀缺（靠售后拆解与台架复现积累，[DEV-06](DEV-06-场景库与数据闭环.md) 数据闭环供料）、分布外泛化无保证。

## 3. 手算实例（数字自洽，均为教学示意值）

### 实例 1：静置自放电筛查内短路

NCM 包（100 Ah/单体）静置过夜 12 h：单体 A 电压降 8 mV，其余单体平均降 2 mV；该 SOC 点 dOCV/dSOC = 2 mV/%（与 ALG-02 同量级）。

- 换算：A 的 ΔSOC = 8/2 = 4%，其余 ≈ 1%；
- 自放电电流：A ≈ 4%×100 Ah/12 h = **0.333 A**；其余 ≈ 0.083 A；
- **异常漏电流** ≈ 0.333 − 0.083 = 0.25 A → 等效并联内短路电阻 R_iscr = 3.7 V/0.25 A ≈ **14.8 kΩ**；
- 判据（示意）：异常自放电 > 3 × 组内中位数 → 标记"软短路疑似" → 叠加温升证据升级处理（FLT-01 分级承接）。

### 实例 2：残差窗口的 3σ 检验

健康段残差统计：均值 ≈ 0，σ = 3 mV（示意）。某 500 帧滑动窗口残差均值 = +11 mV：

- 单帧看：11 mV ≈ 3.7σ，偶发尚可解释；
- 窗口看：均值的标准误 = σ/√N = 3/√500 ≈ **0.13 mV** → 11 mV ≈ 82 个标准误 → **系统性偏移实锤**；
- 结论：单帧残差是噪声，窗口统计才是诊断——同一条数据，问法不同，结论完全不同。

## 4. 工程实态

- 量产主力仍是阈值矩阵（FLT-01）+ 少量一致性诊断（压差/温差/自放电分组统计）；
- 模型残差诊断在高端车型与云端（[GEN-2](GEN-2-云端辅助BMS.md)）逐步落地：云端算力充裕、可跑更复杂的模型与统计；
- 诊断结论**不能直接跳闸**——必须走 FLT-01 的分级链条与 ISO 26262（S-07）的诊断覆盖要求；
- GB 38031（S-01/S-02）的热扩散要求使"内短路早期发现"成为安全链条的上游课题。

## 5. 常见误区

1. 把模型失配当故障——参数未随老化/低温更新，残差全包飘红（先修模型再谈诊断，ALG-10）；
2. 单帧残差定罪——实例 2 展示的噪声陷阱；
3. 内短路只看电压——必须电-热交叉验证，单一证据链不足以支撑重动作；
4. 诊断结果绕过分级直接断高压——诊断是"发现"，处置要过 FLT-01 的动作绑定与 FTTI 预算（[SAFE-04](SAFE-04-安全机制与FTTI.md)）；
5. 数据驱动诊断拿正常数据训练就敢上线——故障类样本稀缺时，分类器的"正常"判决不可信。

## 6. 自测

**Q1**：残差诊断中，"单体外电压残差异常但相邻单体差分正常"指向什么？为什么？
**Q2**：实例 1 中若 dOCV/dSOC = 0.1 mV/%（LFP 平台段），同样 8 mV 压降意味着什么？说明什么工程难点？
**Q3**：为什么诊断算法强调"窗口统计"而不是"单帧阈值"？

<details><summary>答案</summary>

- Q1：指向该路采样链（线束/连接器/AFE 通道）故障。差分正常说明两单体真实的相对状态没变——只有"测量"这一侧在说谎；若电芯本体劣化，与邻居的差分也会异常。
- Q2：ΔSOC = 8/0.1 = 80%——荒谬的数字，说明平台段 dOCV/dSOC≈0 时"电压差→SOC"换算完全失效，自放电筛查失去分辨率。这是 LFP 包做内短路筛查的固有难点：只能靠更长的静置窗口、库仑差或外部证据补偿。
- Q3：单帧残差被测量噪声与工况瞬态污染，误报率不可控；窗口统计把随机噪声平均掉（标准误 ∝ σ/√N），系统性偏移才浮出——本质是把"防抖"从时域搬进统计域。
</details>
