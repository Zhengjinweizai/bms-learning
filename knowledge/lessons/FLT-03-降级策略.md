# 课程 FLT-03：降级策略

> 对应节点 `FLT-03`（[../domains/09-故障处理.md](../domains/09-故障处理.md)）｜ 前置：[FLT-01](FLT-01-故障分级.md)、[SYS-01](SYS-01-功能清单.md)（建议）｜ 预计用时 45 min
> 数字规则：文中所有功率/比例数字均为**教学示意值**。

## 1. 为什么需要在"正常运行"与"断高压"之间设中间态

断高压是最重的处理（[FLT-04](FLT-04-断高压与安全态.md)），但大多数故障并不需要立刻断电：

- 温度传感器断线 ≠ 电池危险，只是"看不清了"；
- 绝缘轻微下降、通信偶发丢帧——都还有观测和应对的余地。

若处理只有"不管"和"断电"两档，要么漏安全，要么滥断电（高速失速本身就是 HARA 里的危害源）。降级（derating / limp-home，跛行回家）就是中间安全态：**限制功率与功能，换取"继续安全行驶到可停车处"的能力**。节点约束点题：降级需与 VCU 联动执行；进入/退出条件需明确。

## 2. 机制展开：动作谱系、执行链路与进入/退出

**（1）降级动作谱系（从轻到重，示意）。**

```
提示 → 限充电功率 → 禁止充电 → 限放电功率（如 40%）→ 限速（VCU 限扭）→ 停车后禁上高压 → 断高压
```

每一档都是"能力削减换风险下降"，选档依据是 FLT-01 的故障等级 + 故障的具体后果面（影响放电？影响充电？影响测量可信度？）。

**（2）执行链路：BMS 请求，VCU 执行。** BMS 通过 CAN 发送功率限制值/使能标志，VCU 在扭矩仲裁中执行——权限划分同 [THM-03](THM-03-整车热联动.md)：**BMS 管"电池还能给多少"，VCU 管"整车怎么用"**。两侧状态机必须约定一致（报文丢失时 VCU 按保守默认执行）。

**（3）与 SOP 的关系：两层分开。** SOP（`ALG-06`）是正常降额（温度/SOC/健康状态的物理限制），故障降级是在 SOP 结果上再乘故障系数或直接钳位。**架构上不许混**——把热降额当故障报出来，用户会以为车坏了。

**（4）进入/退出条件明确化。** 进入 = FLT-01 分级触发（有防抖与迟滞）；退出 = 故障消失 + 迟滞 + **观察窗**（如持续 5 min 无复发，示意），部分等级要求下电周期重置。退出条件与进入条件同样要写进故障矩阵，缺了就是"进去容易出来难"。

## 3. 手算实例：限功率级联推演（教学示意值）

背景：峰值放电 100 kW 的系统。

**场景推演：一个温度传感器断线（开路，读数 −50 °C 非法值）**

1. 硬件自检判断线 → 二级故障 → 该模组温度不可信 → 放电功率钳位至 40%（故障系数，示意）；
2. 同时环境 −10 °C，SOP 热降额允许 60 kW（示意）——两条限制取 **min(40 kW, 60 kW) = 40 kW**；
3. 用户地板电请求 90 kW → BMS 应答可用功率 40 kW → VCU 按此限扭——仪表同步提示"动力受限"（体验闭环）。

**恶化推演：同模组再断 2 个传感器 → 可信测温全失**

- 测量不可信比单点故障严重：最热点温度完全盲区（[THM-01](THM-01-温度布点.md)）→ 升三级：功率钳位至 10%（10 kW，示意）+ HUD 请求靠边；
- 10 kW 仍可维持低速行驶（示意 20~30 km/h）——**降级保留的不是性能，是"能挪到安全地带"的能力**；
- 若此时再叠加"单体过温四级"（真实危险，不只是看不见）→ 断高压路径（FLT-04），在已减速的时机断开，次生风险被前置的降级大幅压低——**这就是"降级为断高压争取非危险时机"的设计思想**。

## 4. 工程实态

- 跛行模式的用户体验（限多少功率、能开多远、提示文案）是主机厂与电池厂联合定义的标定项；
- 退出常见两类：故障消失 + 观察窗自动恢复（可逆类）；下电重上电恢复（保守类）；安全相关不可逆故障必须检修（FLT-02 恢复属性）；
- 整车级约束：BMS 降级不得引发转向/制动助力等底盘功能意外失效——那是 VCU/底盘域的联动安全，BMS 需提供"我即将降级"的前置通知；
- GB/T 38661-2020（S-03）对故障状态下的功能表现有要求（条款待核对）。

## 5. 常见误区

1. 把降级当惩罚、越狠越安全——过度降级制造高速失速风险，反而引入新的危害；
2. BMS 悄悄限功率不通知 VCU/用户——状态机不匹配导致整车行为怪异，用户感知"车抽风"；
3. 退出无迟滞无观察窗——故障闪变时功率跟着闪变，动力忽大忽小；
4. 把正常 SOP 降额显示成故障降级——冬天动力弱 ≠ 车坏了，语义混淆直接伤害售后分流（FLT-06 误报工单）。

## 6. 自测

**Q1**：为什么"测量可信度丧失"（传感器全断）比"单点数值越限"更严重？
**Q2**：故障系数与 SOP 为什么取 min 而不是相加/覆盖？
**Q3**：为"单体过温三级"设计一个退出条件。

<details><summary>答案</summary>

- Q1：单点越限还能靠"限到安全包络内"兜底；测量全失意味着最热点是否危险**不可知**——不可知比可知的危险更危险，只能按最坏假设钳到最低档并引导停车。
- Q2：两条限制是不同性质的约束（物理能力 vs 故障保守假设），任何一条都独立成立，能力取交集即 min。相加无物理意义；"覆盖"（故障系数直接顶掉 SOP）会在故障系数宽于 SOP 时放开物理限制——越权。
- Q3（示意答案）：单体最高温 < 阈值 − 迟滞（如阈值 55 °C → < 50 °C，示意）持续 5 min + 期间无新故障 + 温升速率正常（< 2 K/min，示意）→ 退出三级、恢复至 SOP 决定的功率；若短期内复发 → 升级处理（等级 +1，示意规则）。
</details>
