# 课程 GEN-2：云端辅助 BMS——车端保命，云端进步

> 对应节点 `GEN-2`（[../domains/00-跨域层-架构与代际.md](../domains/00-跨域层-架构与代际.md)）｜ 前置：`GEN-1`、`ARCH-CE`（建议先读）｜ 预计用时 35 min
> 数字规则：文中所有具体数字凡未挂标准/论文者均为**教学示意值**，用于建立量级直觉，不是实测数据。

## 1. 为什么需要：让每辆车"吃"到车队的经验

GEN-1 的三大天花板（精度/迭代/认知）有一个共同解：把车队数据回流、把云端算力引入，让车端算法"持续变好"。GEN-2（云端辅助，Cloud-assisted BMS）的定义：**车端控制为主，云端提供诊断/标定/模型更新**（domain 定义）。

关键词是"辅助"：云端改进车端，但绝不替代车端的安全决策——这是 GEN-2 与"云控"的分界线，也是功能安全底线。

## 2. 机制：云端的三类产物与一条铁律

### 2.1 三类产物

1. **诊断类**：SOH 趋势、故障根因聚类、批次质量监控（数据方法谱系见 S-28/S-29）；
2. **标定类**：参数包（OCV 表、容量、保护阈值边界内的优化），经 OTA 下发（`SW-06`）；
3. **模型类**：修正后的模型参数/轻度模型更新——注意：影响安全行为的更新一律按软件升级管理（UN R156，S-15）。

### 2.2 一条铁律：断网功能完整

domain 约束：断网时功能必须完整。GEN-2 的合格判据：**拔掉网线，安全功能一个不少，降级的只是"变好的速度"**。

### 2.3 合规双翼

- 软件更新：UN R156（SWUP，S-15）——云端产物下发必须走管理体系；
- 数据安全：UN R155 / ISO/SAE 21434（S-14/S-08）+ 数据主权与隐私（domain 约束）。

## 3. 工程案例：断网场景下的功能降级推演（核心案例）

场景：车辆进入长时间无网环境（地下车库/远程山区），车端有 4G 模组但失联 48 h（教学示意值场景）。逐功能推演：

| 功能 | 在网表现 | 断网 48 h 表现 | 降级原因 |
|---|---|---|---|
| SOC/续驶显示 | 本地估计 + 云端参数定期修正 | 本地估计照常，参数停更 | 精度演进暂停（非失效） |
| 充电控制 | 本地闭环 + 云端策略优化 | 本地闭环完整 | 云端优化缺位 |
| 热管理 | 本地控制 | 完整 | 无 |
| 故障保护/断高压 | 本地闭环 | 完整，毫秒级不变 | 无 |
| 故障报警 | 本地报警 + 远程通知 | 本地报警正常，远程通知缺位 | 链路依赖项 |
| 云端 SOH 更新 | 周期更新 | 暂停，用最近一次有效值 | 链路依赖项 |
| OTA | 后台下载安装 | 暂停（恢复后续传） | 链路依赖项 |
| 远程诊断/查看 | 可用 | 不可用 | 纯云端功能 |

**推演结论**：降级集中在三类——"精度增强、远程服务、模型更新"；安全闭环零降级。设计验收时可按此表逐格测试（观点级方法）。

## 4. 工程实态

- 当前量产头部车型的普遍形态（观点级）：电池数据上云 + OTA + 云端诊断已商品化。
- 商业样本：LG 后市场服务矩阵（S-20，细节待 P-03）；主机厂自建电池云为主流（观点级）。
- 上云数据范围是"法规 × 用户授权 × 流量成本"的交集，各家口径不同（观点级）。

## 5. 常见误区

1. "云端辅助 = 云端控制"——云端只产出"建议/参数/模型"，执行与安全判断永远在车端。
2. "断网 = 功能残废"——正确的验收口径是"安全功能完整、增强项暂停"。
3. "云端 SOH 比车端准，车端直接用就行"——云端结论下发即软件/标定变更，须走 UN R156 流程与车端验证，不能旁路（S-15）。

## 6. 自测

**Q1**：用"一条铁律"复述 GEN-2 的验收标准。
**Q2**：云端识别出某批次电芯容量衰减偏快，到"用户车端用上修正后的容量"之间要经过哪些环节？
**Q3**：断网期间发生的故障，事后云端还能分析吗？靠什么？

<details><summary>答案</summary>

- Q1：拔掉网线，安全功能一个不少；降级的只是"变好的速度"——增强项暂停，安全闭环完整。
- Q2：云端数据印证 → 形成参数包 → UN R156 管理体系评审（S-15）→ OTA 签名下发 → 车端验证与版本管理 → 生效。任一环节断开则不生效。
- Q3：能。车端数据记录功能（`SW-07` 类）本地缓存事件与摘要，恢复联网后补传——"断网不丢数据"是云边协同设计的默认要求（推论级，工程实态口径）。
</details>
