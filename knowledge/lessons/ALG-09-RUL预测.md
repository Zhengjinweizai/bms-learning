# 课程 ALG-09：RUL 剩余寿命预测——把 SOH 曲线延伸到未来

> 对应节点 `ALG-09`（[../domains/06-核心算法.md](../domains/06-核心算法.md)）｜ 前置：[ALG-05](ALG-05-SOH定义与老化.md)（必看）、[ALG-03](ALG-03-数据驱动SOC.md)（建议）｜ 预计用时 45 min
> 数字规则：文中所有具体数字凡未挂标准/论文者均为**教学示意值**。

## 1. 为什么需要它

SOH 是"现在"，RUL（Remaining Useful Life，剩余寿命）是"未来"：**电池离失效阈值还有多久**。它不直接保护电池，却直接定价电池：

1. **保修预留金**：8 年质保的钱按 RUL 分布提取；
2. **残值、BaaS 与二手定价**：换电/租赁月费与二手车价本质都是"卖剩余寿命"（[GEN-2](GEN-2-云端辅助BMS.md) 云端价值的主要兑现点，域六导语）——SOH 是截面，RUL 才是趋势；
3. **梯次利用决策**：车用到几成退役、还能干几年，决定 [CHM-04](CHM-04-梯次利用.md) 的经济账。

EV 惯例取容量衰减到 80% 为 EOL（end of life）阈值（工程共识，示意）。

## 2. 机制展开

### 2.1 输入与输出

- **输入**：SOH 轨迹（ALG-05 在线估计的历史序列）+ 工况统计特征（温度分布、倍率分布、吞吐电量）+ 化学体系先验；
- **输出**：到达 EOL 的时间**分布**（RUL = t_EOL − t_now）——不是点估计，置信区间随预测视界（horizon）变宽（节点约束）。

### 2.2 模型族（由简到繁）

| 模型族 | 形式 | 适用 |
|---|---|---|
| 经验式 | 平方根式 Q_loss = k√t（扩散控制 SEI 生长的经典形式）；双指数 a(1−e^(−t/τ₁)) + b(1−e^(−t/τ₂))（快+慢两过程） | 少数据起步、可解释 |
| 半经验 | 线性基底 × 工况加速因子（温度用 Arrhenius 型、倍率/DOD 修正） | 车端可算的工程折中 |
| 数据驱动 | SOH 序列 + 特征 → LSTM/GPR 预测轨迹与区间（S-28/S-29 综述谱系） | 云端、大数据在手的场景 |

### 2.3 两条铁律（节点约束点题）

1. **外推即风险**：用 2 年数据预测 8 年 = 4 倍外推，且"膝点"（knee point，老化后期衰减加速的非线性拐点）可能在数据之外；
2. **分布外泛化差**：训练集没有的工况/新体系（[CHM-02](CHM-02-钠电适配.md)/[CHM-03](CHM-03-固态电池适配.md)）预测无依据。

## 3. 手算实例（数字自洽，全为教学示意值）

### 实例 1：平方根式外推

某车观测（教学示意数据）：1 年容量损失 4.2%、2 年 6.0%、4 年 8.4%。验证平方根式 Q_loss = k√t：k = 4.2/√1 = 4.2；6.0/√2 = 4.24；8.4/√4 = 4.2 → 拟合极佳，**k ≈ 4.2 %/√年**。
- 外推 8 年：loss = 4.2×√8 = **11.9%** → SOH ≈ 88.1%；
- RUL（到 20% 损失）：√t = 20/4.2 = 4.76 → t = **22.7 年** → RUL ≈ 22.7 − 4 = 18.7 年。

**教学警示**：这个"18.7 年"几乎肯定是乐观的——平方根式越老越慢，且未建模膝点与工况突变。经验式外推必须叠加不确定性，不能当承诺。

### 实例 2：双指数的"永不到寿"陷阱

已拟合参数（教学示意值）：a = 3.5%、τ₁ = 0.8 年（SEI 快相）；b = 9%、τ₂ = 6 年（慢相）。

- 外推 5 年：loss = 3.5(1−e^(−5/0.8)) + 9(1−e^(−5/6)) = 3.5×0.998 + 9×0.565 = 3.49 + 5.09 = **8.6%** → SOH ≈ 91.4%；
- 但双指数的渐近极限 = a + b = **12.5% < 20%** → 该模型下**永远到不了 EOL**（RUL = ∞）——荒谬结论；
- 处理：外推前必须检查模型渐近行为；饱和型经验式只适合预测"近期"，长周期要换含线性/加速项的模型或分段建模。

### 实例 3：置信区间决定商业决策

GPR/集成模型给出 5 年后 SOH = 91.4%，95% CI ±3%（示意）：

- 均值口径：距 80% 还有 11.4% 余量；
- **下界口径**：91.4 − 3 = 88.4%，余量只剩 8.4%；
- 保修预留金必须按**下界**计提，而不是均值——差的 3 个点就是财务口径与工程口径的分界线。

## 4. 工程实态

- 主战场在云端（GEN-2/[ARCH-CE](ARCH-CE-云边协同.md)）：车端只存 SOH 轨迹与工况统计特征，训练与外推在云端；量产现状以"保守经验式 + 云端统计修正"为主，学术上的 LSTM/Transformer 尚未大规模上车（工程实践观察，综述 S-28/S-29）；
- RUL 输出下游：残值评估、保修精算、梯次筛选、召回预警（成批车辆的衰减轨迹整体漂移 = 设计/工况问题）；
- 数据基础依赖公开数据集（S-32/S-33）与车队真实数据闭环（DEV-06）。

## 5. 常见误区

1. 拿出厂典型衰减曲线外推个体、又忽略膝点（knee point，老化后期衰减加速的拐点）——个体差异与非线性拐点都会让预测严重偏离，LFP 平台段容量估计本就失真（ALG-01），RUL 会在膝点跳变；
2. 把 RUL 当保证值对用户承诺——商用必须用置信下界（实例 3）；
3. 训练分布外硬预测——新体系/新快充策略没有数据支撑，预测就是编造；
4. 混淆容量口径与功率口径的 EOL——动力电池也可能"功率先到寿"（ALG-05/ALG-06）。

## 6. 自测

**Q1**：为什么平方根式外推长周期必然偏乐观？
**Q2**：实例 2 中 RUL = ∞ 暴露了经验式建模的什么问题？工程上怎么处理？
**Q3**：一辆车 3 年 SOH_C = 95%，能否直接回答"还能用几年"？缺什么信息？

<details><summary>答案</summary>

- Q1：√t 的斜率随时间递减（老化"越老越慢"），而真实老化有膝点加速项；且平方根式只描述 SEI 类单一机理，循环老化、LAM 加速等未进入方程。
- Q2：经验式只保证"拟合段"行为，外推段的渐近行为未经验证——饱和模型给出永不到寿的荒谬输出。处理：外推前检查渐近值与曲率，长周期换模型（含线性项/膝点项）或分段建模，并全程带置信区间。
- Q3：不能。SOH 是单点截面；需要衰减轨迹（多时点）、该车的工况特征（温度/倍率/DOD 分布）、体系先验与不确定性——即本课 2.1 的完整输入，才能给出带区间的 RUL。
</details>
