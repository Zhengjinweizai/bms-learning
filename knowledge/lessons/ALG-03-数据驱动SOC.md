# 课程 ALG-03：数据驱动 SOC——让数据自己学会"读"电池

> 对应节点 `ALG-03`（[../domains/06-核心算法.md](../domains/06-核心算法.md)）｜ 前置：[ALG-01](ALG-01-安时积分与OCV校正.md)、[ALG-02](ALG-02-EKF状态估计.md) ｜ 预计用时 45 min
> 数字规则：文中所有具体数字凡未挂标准/论文者均为**教学示意值**。

## 1. 为什么需要它

ALG-02 的模型法准但贵：OCV 表要按温度×SOC×老化标定网格（ALG-10），滞回要建模，每换一版电芯全部重来。数据驱动的诱惑是**跳过建模，直接学"测量序列 → SOC"的映射**：

1. **绕开人工 OCV 标定**：LFP 平台段（ALG-01/02 的老大难）对学习模型只是"一段难学的曲线"，不需要人工构造锚点；
2. **天然拟合非线性**：迟滞、温度、老化特征都可作为输入喂进去；
3. **吃云端算力红利**（[GEN-2](GEN-2-云端辅助BMS.md)/[ARCH-CE](ARCH-CE-云边协同.md)）：训练在云端，车端只推理。

代价同样真实：外推失效、可解释性差、功能安全论证难（[SAFE-06](SAFE-06-AI安全论证.md)）——所以节点成熟度是 `evolving`。

## 2. 机制展开

### 2.1 三条主流路线

| 路线 | 输入 → 输出 | 特点 |
|---|---|---|
| 人工特征 + 浅层回归（SVR/GPR 等） | 特征向量（电压、dU/dt、累计安时…）→ SOC | 轻量、可上车；特征工程是灵魂 |
| 序列深度学习（LSTM/GRU/TCN） | [U, I, T] 滑动窗口时序 → SOC | 自动学特征；数据与算力需求大（方法谱系见 S-28/S-29） |
| 融合架构 | 学习模型当 EKF 的"观测器插件" | 物理约束兜底，量产友好方向 |

### 2.2 训练目标与符号逐个解释

$$\min_\theta \sum_i \big\| f_\theta(x_i) - y_i \big\|^2$$

- **x_i**：第 i 个输入（窗口时序或特征向量）；
- **y_i**：标签 SOC——**来自离线标定实验**（小电流放电 + OCV 锚定 + 高精度库仑计数，即 ALG-01 方法反过来当地尺）。数据驱动最贵的不是 GPU，是**标签与工况覆盖**；
- **f_θ**：模型（网络权重 / GPR 超参），θ 为待学参数；
- **GPR（高斯过程回归）的特殊性**：输出均值 μ + 方差 σ²，σ² 天然就是"置信度"——这是它在安全敏感场合常被选中的原因。

### 2.3 失效回退（节点约束点题）

置信度 σ 或新工况检测器超阈值 → 本拍弃用网络输出 → 回退 EKF/安时积分（ALG-01/02），事件记录回传云端（[DEV-06](DEV-06-场景库与数据闭环.md)）。

## 3. 手算实例（数字自洽，均为教学示意值）

### 实例 1：最近邻回归玩具版 + 外推失效演示

训练集（25 °C 标定，斜率与 ALG-02 的 dOCV/dSOC ≈ 2 mV/% 同量级）：(3.72 V → 60%)、(3.70 V → 50%)、(3.68 V → 40%)。

- 查询 A：U = 3.69 V，25 °C。距离：|3.69−3.70| = 0.01，|3.69−3.68| = 0.01，|3.69−3.72| = 0.03 → 前两个并列最近，取均值 → **SOC ≈ 45%**。合理。
- 查询 B：U = 3.69 V，**−10 °C**。训练集没有低温样本，最近邻照样返回 45%——但低温下同电压对应的真实 SOC 与 25 °C 完全不同 → **错得毫无自觉**。这就是"训练分布外（OOD, Out-of-Distribution）外推失效"的最小可复现演示。

### 实例 2：置信度门控回退

设定回退阈值 σ_max = 2%（教学示意值）：

- 工况一（训练流形内）：GPR 输出 SOC = 45%，σ = 0.3% < 2% → 采用；
- 工况二（−10 °C 冷启动）：σ = 4.0% > 2% → 弃用，本帧改用安时积分值 43.5%（上一锚点积分而来，示意），并置"低置信"标志上报云端。

要点：回退不是"关机"而是**降级到物理方法**——数据法叠在模型法之上，不是替代。

## 4. 工程实态

- 量产车端 SOC 主力仍是 ALG-01/02 的模型法；数据驱动当前主要在**云端**做残差修正、异常检测与标定辅助（工程实践观察）；
- 车端落地障碍：MCU/NPU 算力与内存预算、可解释性、ISO 26262（S-07）对软件组件确定性的要求——ML 组件的安全论证是独立课题；
- 方法成熟度全景见综述 S-28/S-29；AI/ML 在 BMS 的产业化评估见 S-21（全文待取 → P-11）。

## 5. 常见误区

1. "有了深度学习就不用建模"——标签本身来自物理方法；外推失效必须物理法兜底；
2. 把训练集误差当车端精度——训练分布 ≠ 全生命周期工况（老化 8 年的车不在训练集里）；
3. 标签带病入库——用漂移的库仑计数当真值，网络把传感器误差学成"物理"；
4. 只输出点估计不给置信度——车上不可用（无法回退、无法审计）。

## 6. 自测

**Q1**：为什么数据驱动 SOC 必须配回退机制？回退到哪里？
**Q2**：GPR 相比同等精度的 LSTM，在车端工程上多一个什么关键优势？
**Q3**：查询 B"错得毫无自觉"的根源是什么？给至少两条缓解措施。

<details><summary>答案</summary>

- Q1：模型在训练分布外（低温/老化/新工况）输出不可信且误差无界，直接采用有安全风险；回退到物理方法（EKF/安时积分），误差有界、机理可审计。
- Q2：GPR 自带预测方差（置信度），可直接做门控回退；LSTM 需要额外的不确定性量化（深度集成、MC Dropout 等）。
- Q3：根源是最近邻假设"特征空间相邻 ⇒ 输出相近"，温度维度缺样本时假设崩塌。缓解：把温度纳入特征并覆盖全温域训练；OOD 检测（置信度/密度估计）触发回退；物理模型兜底融合。
</details>
