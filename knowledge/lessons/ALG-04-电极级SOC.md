# 课程 ALG-04：电极级 SOC（eSOC）——把估计钻进电芯内部

## 1. 为什么需要它

前几课的 SOC 估计的都是"整芯级"标量。但锂离子电池是**两个电极的跷跷板**：充电 = 锂从正极脱出、嵌入负极。老化后跷跷板两端会各自变形：

- **LLI（锂库存损失，Loss of Lithium Inventory）**：SEI 生长吃掉可用锂 → 满充时"锂先没了，负极还没满"；
- **LAM（活性材料损失，Loss of Active Material）**：某一极活性材料缩水 → 该极先到边界。

整芯 SOC 看不见"锂分布在哪个电极、离析锂边界还有多远"。eSOC（electrode SOC）把估计对象细化到**每个电极各自的荷电状态**，才能回答快充最关心的问题：**负极离析锂边界还有多远？**（与 [CHG-03](CHG-03-析锂抑制.md) 直接衔接。）

## 2. 机制展开

### 2.1 半电池 OCV 与全电池

$$U_{cell} = U_{pos}(\theta_{pos}) - U_{neg}(\theta_{neg})$$

- **U_pos(θ_pos)**：正极半电池 OCV 曲线；**θ_pos** = 正极当前嵌锂量 ÷ 正极可嵌容量（0~1，嵌锂化学计量比 stoichiometry）；
- **U_neg(θ_neg)**：负极半电池 OCV 曲线——石墨在大部分区间极平，这正是全电池出现电压平台（ALG-01 讲过的 LFP 现象）的机理来源之一；
- **θ 的窗口**：每个电极有工作窗口 [θ(0%), θ(100%)]，整芯 SOC 就是把窗口边界之间线性推进的"进度条"。

### 2.2 老化如何移动窗口（符号逐个解释）

- **LLI**：可用锂总量减少 → 满充时两极都"差一点才到顶"→ 端点偏移，新鲜电芯的 OCV-SOC 表对老化电芯产生系统性偏差；
- **LAM_neg**：负极容量 C_neg 缩水 → **N/P 比**（负极容量 ÷ 正极容量；设计值 > 1 以留防析锂余量，**文献典型 1.05~1.15——S-90**：Mu et al. 2022 系统研究，N/P<1 即析锂，2026-11-22 核实 P-72）下降 → 满充时负极先顶满；
- **eSOC 估计** = 在线联合估计 (SOC + 电极容量/θ 窗口)——是 ALG-02 联合估计框架（S-17）把参数向量从 [容量, 内阻] 换成 [电极容量, θ 窗口] 的推广；依赖半电池曲线先验与高精度电压，对传感与模型要求高（节点约束）。

## 3. 手算实例：N/P 比退化如何吃掉析锂余量（数字自洽，全为教学示意值）

新鲜电芯：C_pos = 100 Ah，C_neg = 108 Ah → **N/P = 1.08**。

1. 满充：正极脱锂 100 Ah（到 100%），负极嵌锂 100/108 = **92.6%** → 负极余量 7.4%——这就是防析锂的设计余量；
2. 老化：负极 LAM 10% → C_neg = 108 × 0.9 = **97.2 Ah** → N/P = 97.2/100 = **0.972 < 1**；
3. 此时满充改由负极限制：充入 97.2 Ah 时负极 θ_neg = 100%（顶满），正极只走到 97.2%；
4. 整芯 SOC 在新旧两种状态下都显示"100%"，但 eSOC 视角看到：**负极余量从 7.4% → 0、正极还剩 2.8% 没脱完**——若仍按新鲜参数在快充末段施加大电流，负极表面电位跌破 0 V（vs Li/Li⁺）→ 析锂。

结论：整芯 SOC 对"余量消失"全程失明，eSOC 是看见它的最小手段。

## 4. 工程实态

- 量产车端目前**不做完整 eSOC**：需要半电池曲线先验 + 老化参数在线可观测，传感精度与算力都是门槛（工程共识；节点成熟度 `evolving`）；
- 实验室/云端路径成熟：**dQ/dV（差分容量）分析**——容量对电压求导后的峰位置/峰高对电极退化敏感，用于离线电极平衡诊断与老化归因；
- 学术前沿正朝车端收缩：**AABC 2026 "Estimating SOC and SOH" 专场，Plett 报告主题即 eSOC 校正老化偏差**（线索登记于 [../../radar/conferences/aabc-2026.md](../../radar/conferences/aabc-2026.md)，P-04 待核对——会议未开，本课不引用其内容）；
- 潜在落地场景：快充末端析锂保护（CHG-03）、老化归因（与 [ALG-08](ALG-08-故障诊断算法.md) 互补）、梯次筛选（[CHM-04](CHM-04-梯次利用.md)）。

## 5. 常见误区

1. "整芯 SOC=100% 就代表负极安全"——N/P 退化后恰恰相反（实例）；
2. 把 eSOC 当"每个电极各自的电池 SOC"——它是化学计量比进度条，锚点是半电池 OCV；
3. 假设 N/P 比与窗口边界终生不变——它们正是老化的输出；
4. 以为 eSOC 要往电芯里加传感器——主流路线仍是"外部电压/电流 + 模型可观测性"。

## 6. 自测

**Q1**：用"跷跷板"语言解释：为什么 LLI 后满充时"两极都差一点才到顶"？
**Q2**：实例中 N/P 从 1.08 降到 0.972，为什么满充限制极从正极换成了负极？
**Q3**：dQ/dV 为什么比直接看 OCV 曲线更能暴露电极退化？

<details><summary>答案</summary>

- Q1：锂是搬运对象，库存变少后同样的充电动作可搬运的总量变少；"满充 = 可用锂全部搬到负极"，锂少了，两边自然都到不了各自的几何顶点。
- Q2：满充由"先到边界的一极"限制。C_neg 缩水到 97.2 Ah 后，负极窗口容量 < 正极 100 Ah，负极先顶满。
- Q3：求导把平缓的 OCV 曲线变成尖锐峰，峰位置/高度直接对应相变平台与电极容量——电极退化的微小移动在峰上被放大可见，原始曲线里却被淹没。
</details>
