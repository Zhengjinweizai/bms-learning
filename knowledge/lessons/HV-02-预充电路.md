# 课程 HV-02：预充电路与预充策略

> 对应节点 `HV-02`（[../domains/05-高压.md](../domains/05-高压.md)）｜ 前置：无（本域学习路径起点）｜ 预计用时 45 min
> 数字规则：文中具体数字凡未挂标准/来源者均为**教学示意值**，选型须以器件规格书为准。

## 1. 为什么需要预充电

电控/逆变器的直流支撑电容（DC-link capacitor，母线电容）在整车上电前电压 ≈0。若直接闭合主继电器，电池（数百伏）对近乎短路的电容放电：

- 浪涌电流仅受线束与触点电阻限制，可达 kA 级（教学示意量级）；
- 继电器触点被电弧烧蚀甚至**熔焊**——正是 [HV-04](HV-04-粘连检测.md) 粘连故障的首要成因；
- 电容承受反复大电流应力，寿命受损。

预充（Pre-charge）= 上电前经**预充电阻**给母线电容缓冲充电，把冲击电流限制到继电器可承受的量级。节点约束点题：预充电阻功率与预充时间窗；预充失败判定（电压爬升率）。

## 2. 机制展开

**（1）回路拓扑**：预充继电器 + 预充电阻串联后**并联在主正继电器两端**。典型时序（细节见 [HV-05](HV-05-上下电时序.md)）：闭主负 → 闭预充 → 母线电压爬升至目标（90%~95% 电池电压）→ 断预充 → 闭主正。

**（2）充电过程是 RC 电路**：

$$V_{bus}(t) = V_{pack}\left(1 - e^{-t/\tau}\right), \quad \tau = R_{pre} \times C_{bus}$$

- R_pre：预充电阻；C_bus：母线电容总和；
- 达 90% 需 t = τ·ln(10) ≈ 2.3τ；95% 需 ≈ 3.0τ——**目标每提高 5%，时间多约 1/3**。

**（3）电阻的能量与功率**：充电能量几乎全部耗在电阻上：
- 总能量 E = ½C_bus·V_pack²（终态电容储能）；
- 峰值功率 P₀ = V_pack²/R_pre（t=0 时刻），随电压爬升指数衰减；
- 选型依据是**脉冲能量（J）与脉冲序列降额，不是连续功率（W）**——最常见的选型错误。

**（4）失败判定（电压爬升率）**：预充窗口内电压未达目标 → 判预充失败。爬升率还能分型：完全不爬（电阻断线/电容短路/继电器未闭合）vs 爬了但太慢（窗口不够）——维修指向完全不同。

## 3. 手算实例：预充电阻选型（完整四步）

给定：V_pack = 400 V，C_bus = 900 µF，目标 90%，窗口 500 ms（全部教学示意值）。

**第一步：定时间常数。** τ = t / ln(10) = 0.5 / 2.303 ≈ **0.217 s**

**第二步：定电阻。** R_pre = τ / C = 0.217 / 900 µF ≈ 241 Ω → 取 E24 标称 **240 Ω**。复核：τ = 240 × 900 µF = 0.216 s，V(0.5 s) = 400(1−e^(−2.315)) ≈ 360.5 V = **90.1%** ✓

**第三步：能量与功率。**
- E = ½ × 900 µF × 400² = **72 J**（几乎全部落在电阻上）；
- 预充期间平均功率 = 72 J / 0.5 s = **144 W**；
- 峰值 P₀ = 400²/240 ≈ **667 W**（瞬时，指数衰减）；
- 预充电流初值 = 400/240 ≈ **1.67 A**。

**第四步：选型核对（示意）。** 选短时脉冲额定足够的绕线/铝壳电阻（示例量级：连续额定 25 W、单脉冲耐 100 J 级——具体以规格书为准），并核对**重复预充热累积**：60 s 内连续两次预充即 144 J，必须查脉冲序列降额曲线或加冷却时间。

## 4. 工程实态

- 预充回路集成于 BDU（电池配电盒），与主正/主负/快充继电器同板布置；
- 预充失败累计计数并报 DTC，连续失败 → 禁止再上电（防继电器寿命被重试耗光）；
- 800 V 平台：电压更高、C_bus 往往更小，单次能量同量级，峰值电流更可控；
- 新架构出现"主动预充"（半控器件/DC-DC 缓升）替代电阻发热——成本与可靠性仍在博弈。

## 5. 常见误区

1. 按连续功率选预充电阻——应按脉冲能量与脉冲序列降额选；
2. 目标电压定 99%——时间 ≈4.6τ，白白拖慢上电；90%~95% 已够（残差由主正闭合瞬间吸收，量级可接受，示意）；
3. 预充超时一律换电阻——真实原因可能是电容短路、继电器未闭合、采样链故障，按爬升率分型后再修；
4. 忽略主负先闭合时刻的容性电流路径，以及预充电阻的两次预充间热恢复。

## 6. 自测

**Q1**：同参数下把目标改为 95%，预充窗口至少需要多少毫秒？
**Q2**：预充电阻断线与母线电容短路，如何在上电时序中被区分？
**Q3**：800 V/450 µF 与 400 V/900 µF 两个系统，单次预充在电阻上的能量各是多少？

<details><summary>答案</summary>

- Q1：t = τ·ln(20) ≈ 0.216 × 3.0 ≈ **648 ms**（3.0τ）。
- Q2：电阻断线：电压完全不爬且预充回路无电流（若有电流采样）；电容短路：电压停在低压且持续较大电流。两者都判预充失败，但 DTC 分型不同，维修指向不同。
- Q3：½CV²：800 V → ½ × 450 µF × 640000 = **144 J**；400 V → ½ × 900 µF × 160000 = **72 J**。电压翻倍能量翻倍的前提是 C 相同——800 V 系统能量未必更大，取决于 C_bus。
</details>
