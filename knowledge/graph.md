## 使用约定

- **成熟度**：`stable`（有现行标准/成熟工程实践，3~5 年内不会被颠覆）｜`evolving`（已落地但方法仍在快速迭代）｜`frontier`（未收敛，论文/演示多于量产）。
- **`[需补约束]`**：该节点目前只有功能名，缺乏可靠记录的工程约束，需要后续以 A/B 级来源补充。

## 二、最小可学习路径（每个一级域一条）

> 阅读方式：按序学习，从零到"能参与该域工程讨论"的最少概念集。

1. **SYS（边界与架构）**：SYS-01 功能清单 → SYS-02 系统边界 → ARCH-MS 主从式 → SYS-04 网络节点 → SW-05 诊断接口。
   逻辑：先知道 BMS 管什么、管到哪为止，再看它以什么形态存在于整车上。
2. **SAFE（安全设计）**：SAFE-01 ISO 26262 流程 → SAFE-02 HARA → SAFE-03 ASIL 分解 → SAFE-04 安全机制。
   逻辑：功能安全是流程驱动的学科，必须先立流程框架再谈具体机制。
3. **HW（硬件）**：HW-01 AFE → HW-03 电流传感 → HW-04 高压隔离 → HW-02 主控 MCU → HW-05 执行器。
   逻辑：沿"信号链"学习——采集→传输→处理→执行。
4. **SW（软件）**：SW-01 架构 → SW-02 调度 → SW-03 协议栈 → SW-04 状态机 → SW-05 标定诊断。
   逻辑：先立骨架（架构/调度），再通对外（协议），后通行为（状态机）。
5. **HV（高压）**：HV-02 预充 → HV-05 上下电时序 → HV-01 HVIL → HV-03 绝缘监测 → HV-04 粘连检测。
   逻辑：高压安全的一切围绕"先建立、再维持、能撤出"。
6. **ALG（算法）**：ALG-01 安时积分 → ALG-10 ECM → ALG-02 EKF 估计 → ALG-05 SOH → ALG-06 SOP。
   逻辑：模型是根，估计是干；SOC→SOH→SOP 是"状态→老化→能力"的因果链。
7. **CHG（充电）**：CHG-01 接口 → CHG-02 通信协议 → CHG-06 末端控制 → CHG-03 析锂抑制 → CHG-04 充电安全。
   逻辑：先物理连接，再对话，最后是控制策略与安全底线。
8. **THM（热管理）**：THM-01 布点 → THM-02 热模型 → THM-03 整车联动 → THM-04 低温加热。
   逻辑：先测得准，再算得清，再控得住。
9. **FLT（故障）**：FLT-01 分级 → FLT-02 DTC → FLT-03 降级 → FLT-04 断高压。
   逻辑：识别→记录→降级→退出，四级递进。
10. **DEV（开发验证）**：DEV-01 V 模型 → DEV-02 验证阶梯 → DEV-03 HIL → DEV-04 合规测试 → DEV-05 标定耐久。
    逻辑：先流程后台架后法规，最后靠实车数据收口。
